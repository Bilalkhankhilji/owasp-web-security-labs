# OWASP Web Security Labs & Remediation Guide

## Overview
A structured repository documenting analysis, exploitation concepts, and code-level remediation strategies for critical web application vulnerabilities based on the OWASP Top 10 framework.

## Covered Vulnerabilities
1. **SQL Injection (SQLi):** Database query manipulation via unsanitized user inputs.
2. **Cross-Site Scripting (XSS):** Injection of malicious client-side scripts into web applications.
3. **Broken Authentication:** Flaws in session management and credential handling.
4. **Security Misconfigurations:** Default configurations, exposed directories, and verbose error handling.
